## Selected work

### Polygra — real-time multiplayer browser game

Built and deployed a TypeScript game using Cloudflare Workers, Durable Objects, D1, and WebSockets.

- 30 TPS server-authoritative combat with a Durable Object per match.
- Compact binary state updates, reducing recurring player-state payloads from over 150 to under 40 bytes per player.
- Client prediction, server reconciliation, and buffered interpolation with shared movement logic.
- Persistence APIs, retry-safe match settlement, automated tests, and GitHub Actions deployment.

### RISC-V operating system

Developed operating-system components in C using QEMU and GDB, including filesystem functionality, a lazy ELF loader, syscalls, and virtio drivers. The project placed third in UIUC's OS Design Competition.

### [Continuous Game of Life](https://github.com/bfaum/continuous_GOL)

Built a continuous-state cellular automaton in Python and ported grid updates to PyCUDA. The project explores emergent structures, GPU computation, and rendering performance.

### [Domino puzzle and solver](https://github.com/faumben/domino_puzz)

Designed a domino-placement puzzle with global connectivity and local adjacency constraints, built an interactive tool and solver, and investigated a Planar 3-SAT reduction using constraint gadgets.
